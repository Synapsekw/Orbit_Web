BEFORE WE BEGIN

A few useful
answers.

When should we begin?+

Starting early gives the most complete story, but a sequence can begin at any stage where there is meaningful change to document.

Can the same footage support progress reporting?+

Yes. We can plan a capture programme that serves both regular project updates and the final time-lapse edit.

How do we start?+

Share the location, timing and intended use in a project enquiry. We will discuss coverage and delivery with you before a capture plan is agreed.
