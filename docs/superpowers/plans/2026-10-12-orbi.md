# Orbi character and widget implementation plan

**Goal:** Ship the approved Halo Companion as an animated character and an Aria-style widget, with a portable package for the website-owning session.

**Authority:** User selected option 2, requested the complete build, then explicitly requested the widget and coordination with Explore Orbital Aerials redesigns. Implementation proceeds under that authorization.

**Architecture:** Three.js procedural graphite core and silver ribbons, animated face rig, optional shared UI integration. A scoped widget uses the character in its launcher/header, offers a local service guide, and accepts a server-side responder adapter. Art is the non-WebGL fallback. Build a standalone ES module with scoped CSS and relative assets, without modifying website templates or main build configuration.

**Stack:** Existing Three.js, Vite, Node test runner; no new product dependencies.

**Approved reference:** design-concepts/orbi-round-1/02-halo-companion.png.

## Ownership and constraints

- Own src/orbi, public/orbi, orbi-preview, scripts/build-orbi.mjs, tests/orbi* and Orbi handoff documentation.
- Website owner handles final placement, site entrypoints, deployment, and a live chat backend.
- Preserve silver/graphite materials and warm eyes; navy/gold applies to widget styling.
- No secrets or external AI calls in the browser. Prepared responses are identified as a local guide.
- Keep messages in memory only. No collection/submission of contact details; route to the site's contact page.
- Respect reduced motion, offscreen and document visibility; clean up GPU resources/listeners on destroy.
- No Git repository exists here. Do not create a worktree or commit unrelated work.

## Tasks

- [x] Character: write tests for expression safety/reduced motion; build dimensional ribbons, face states, gestures, pointer gaze, lifecycle and fallback. Check at hero and compact sizes.
- [x] Widget: test link validation and local intent routing; build accessible launcher/panel, keyboard controls, mobile modal, local guide, bounded async responder with cancellation/retry, and explicit disclosure.
- [x] Package: generate transparent fallback, optimize delivery sizes, build portable module/CSS, create responsive interactive preview and integration guide.
- [x] Verify: run full project tests, standalone build, browser desktop/mobile, all states, pause, reduced motion, fallback, focus, retry/reset and teardown. Perform independent code review and prepare exact handoff paths to website owner.

## Review focus

1. Reduced motion and context loss must still show Orbi.
2. Destroy/re-mount must not leave RAFs, focus locks or GPU allocations behind.
3. Backend text/links must not inject HTML or navigate to unapproved schemes/origins.
4. Reset/destroy during a delayed response must not append stale results. Closing preserves the request and conversation for reopening, without restoring focus asynchronously.
5. Mobile focus and scroll locks must restore the host page's prior state.
